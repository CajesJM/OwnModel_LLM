# OwnModel LLM

This repository is my practice project for **learning how to build my own AI language model from scratch**.

I'm using this project to understand the basic concepts behind AI and Large Language Models (LLMs), including:

* Model architecture
* Tokenization
* Training
* Text generation
* Datasets
* Transformers
* PyTorch

The project is still a work in progress as I continue learning and experimenting with different approaches to building an AI model.

## Technologies

* Python
* PyTorch
* Gradio

## Goal

The main goal of this repository is to learn and practice the fundamentals of building an AI language model without relying entirely on existing AI APIs or pre-built models.
